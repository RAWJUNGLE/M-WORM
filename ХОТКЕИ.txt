M-WORM — ВСЕ ХОТКЕИ ЧЕРЕЗ "+"
(по коду Work/fm1-base/mworm/worm/worm_ui.c и mworm/app.c)

================================================================================
1. КНОПКА + КНОПКА
================================================================================

HOME + PLAY
    Экран BPM / CLICK: CPU, XRUN, MAX, UND, MISS, LIMdB.
    Примечание: в README указано HOME+GLO — это опечатка, в коде HOME+PLAY.

PLAY + REC (любой порядок нажатия)
    Live Record: включает REC и запускает PLAY. Белые клавиши пишут ноты
    на лету по бегущему курсору.

HOME + SEQ
    Открывает меню EUCLID вместо SEQ PAGE. Если уже в SEQ PAGE или EUCLID —
    переключает между ними.

REC + EDIT
    Окно TRIG CONDITION на странице NOTE TRIG: RETRIG / R.LEN / R.VEL / COND.
    Повторное нажатие EDIT закрывает окно.

GLO + EDIT
    Очистить всю automation текущего трека (все записанные вращения ручек).

EDIT + OCT-
    Очистить automation только четырёх ручек текущего меню.

GLO + SAVE (коротко, вне STEP SEQUENCER)
    Диалог SAVE BANK? -> OCT+ да / OCT- нет. Пишется весь банк.

HOME + SAVE (удержать 2 с)
    Режим обновления прошивки. Сохранение пресета при этом подавляется.
    ВАЖНО: не путать с обычным SAVE 2 с (см. раздел 6).

HOME + OP1..OP4 (чёрные клавиши F#3/G#3/A#3/C#4)
    Открыть страницу синтеза: OP1 NOTE TRIG, OP2 OSC, OP3 AMP, OP4 FLT.
    На экране TRACKS (VOICES) — mute MIDI-дорожек M1..M4.

================================================================================
2. SEL + КЛАВИШИ
================================================================================

SEL + белые клавиши 1..4
    Выбрать аудио-дорожку 1..4. У каждой своей паттерн и свой звук.

SEL + белые клавиши 13..16
    Выбрать MIDI-дорожку: 13 -> M4, 14 -> M3, 15 -> M2, 16 -> M1.

SEL + OP1..OP4 (чёрные F#3/G#3/A#3/C#4)
    Mute аудио-дорожек 1..4.

SEL + HOME + OP1..OP4
    Mute MIDI-дорожек M1..M4.

SEL + D#5 / C#5 / A#4 / G#4
    Mute MIDI-дорожек M1 / M2 / M3 / M4 соответственно.

================================================================================
3. УДЕРЖАНИЕ КНОПКИ + БЕЛАЯ КЛАВИША
================================================================================

Удержать FX / ENV / LFO / GLO / ARP / SEQ примерно 0.5 с, затем нажать
белую клавишу 1..N
    Переключить вкладку/страницу текущего меню. Для SEQ дополнительно
    задаётся видимая страница паттерна.

================================================================================
4. ТРИГГЕР + КНОПКА / РУЧКА
================================================================================

Зажать триггер + OCT- / OCT+   (только в режиме REC)
    Микротайминг шага: -24...+24 тиков (1 тик = 1/24 шага 1x).
    Открывается окно MICROTIMING с крупным значением и шкалой.

Зажать триггер + HOME   (на странице NOTE TRIG, в REC)
    Обзор сдвигов всех 16 шагов текущей страницы: MICROTIMING x/y.
    Столбики вверх — позже, вниз — раньше. После отпускания HOME — возврат.

Зажать триггер + крутить ручку PRESET
    Пресет записывается в шаг как p-lock (7-й слот). Звук самой дорожки
    не меняется. Окно STEP PRESET показывается 2 с, затем возврат
    в предыдущее меню с сохранением вкладки.

================================================================================
5. HOME + РУЧКИ (АЛЬТЕРНАТИВНЫЕ ПАРАМЕТРЫ)
================================================================================

Меню OSC (алгоритм FM)
    K1..K4 = RATIO / FDBK / I.ENV / I.VEL выбранного осциллятора

Меню AMP
    K2 = Release вместо ADS

Меню FLT, страницы 1/2
    K4 = Width фильтра вместо 4-го параметра фильтра

Меню FLT, страницы 3/4 (огибающая фильтра)
    K1/K3/K4 = DRIVE / PAN / VOL огибающей вместо ADSR

Меню LFO
    K1..K4 = MODE / SYNC / SPEED
    Для TIDES: MODE / SLOPE / SMOOTH / SHIFT

Меню ENV (свободная огибающая E4)
    K1/K2 = DEST / DEPTH вместо ADSR

Меню MIDI > LFO
    Доступны дополнительные дорожки LFO 5/6/7

================================================================================
6. ПОДТВЕРЖДЕНИЯ И УДЕРЖАНИЯ
================================================================================

В диалогах SAVE PATTERN?, SAVE BANK?, смене алгоритма и USB-режима:
    OCT+ = ДА / применить
    OCT- = НЕТ / отмена

SAVE коротко
    Диалог SAVE PATTERN? -> OCT+ да / OCT- нет. Паттерн и проект.

SAVE удержать 2 с
    Сохранить звук текущей дорожки в выбранный пресет -> PRESET SAVED.
    Если зажат HOME — вместо этого режим обновления (см. раздел 1).

EDIT коротко
    Выбор паттерна.

EDIT удержать 2 с
    Выбор банка паттернов.

LFO коротко
    Открыть меню LFO; повторное нажатие внутри меню — следующий LFO.

LFO удержать примерно 0.5 с
    LFO MAP прямо в текущем меню без перехода на страницу LFO.
    Белые клавиши 1..8 выбирают LFO, ручка привязывает его к параметру.
