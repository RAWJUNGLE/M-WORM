# M-WORM — руководство пользователя

M-WORM — открытый грувбокс для M-VAVE FM-1. Четыре независимых звуковых трека, каждый со своим
синтезатором (VA или FM), секвенсором на 128 шагов, эффектами и арпеджиатором. Плюс четыре MIDI-трека
M1–M4, которые шлют ноты, CC и PC по USB. Частота рендера — 44.1 кГц, четыре моно-голоса
(по одному на звуковую дорожку).

> Актуально для сборки `fm1-base/mworm`, identity **FM-1_239300**. Второе ядро AC791N в этой сборке
> не используется.

Звуковой тракт каждого трека:

```
TRACK → SEQ → OSC → AMP (E0/E3) → FLT1 / FLT2 (E1/E2) → SENDS → MASTER
```

- **OSC** — два осциллятора; алгоритм **VA** или **FM** задаётся на каждом треке отдельно.
- **AMP** — дисторшн, transient, пан, громкость, драйв; огибающие амплитуды **E0 / E3**.
- **FLT1 / FLT2** — два фильтра (OFF / LP / HP / BP) с резонансом, D/WET и огибающими **E1 / E2**.
- **SENDS** — посылы в эффекты (на каждом треке свой уровень).
- **MASTER** — общий выход с look-ahead пиковым лимитером (индикатор `LIMdB` на экране BPM).

Эффекты **delay / reverb / chorus** — общие для всех треков (настраиваются на странице FX);
уровень посыла каждого трека задаётся на странице AMP → вкладка SEND.

## 1. Установка и прошивка

Подключи FM-1 по USB **data-кабелем** (не только зарядка), напрямую в порт (без хаба).
Закрой другие MIDI-программы (DAW, M-Upgrade и т.п.).

Прошивка ставится с компьютера:

```sh
./flash.sh Work/fm1-base/mworm/build/m-worm.fwsc
```

Скрипт сам создаст окружение и поставит зависимости при первом запуске. Полезные команды:

```sh
./flash.sh --info                         # показать подключённый FM-1
./flash.sh <файл.fwsc>                    # прошить (спросит подтверждение)
./flash.sh <файл.fwsc> --yes              # без подтверждения
./flash.sh <файл.fwsc> --port FM-1 --yes  # выбрать порт по имени
```

После прошивки FM-1 перезагрузится и загрузит M-WORM. Пакет `m-worm.fwsc` (~611 КБ) имеет
идентификатор `FM-1_239300`.

## 2. Экран

| Часть | Что показывает |
| --- | --- |
| Верхняя строка | Номер трека `T1–T4`, текущий паттерн `PT<банк><номер>`, темп BPM, батарея / USB-питание. |
| Заголовок | Название открытой страницы (например `OSC1 FM`, `LFO3`, `FLT2`) и вкладки. |
| Центр | Панель страницы: осциллограф, клавиатура, огибающая, секвенсор и т.п. |
| Низ | Четыре ручки `K1–K4` — параметры текущей страницы. |

Подсветка кнопок: активная страница горит ярко, остальные тускло; `HOME` горит всегда.
Всего 25 экранов (со вкладками — 51 состояние). Скриншоты всех экранов лежат в папке
`скриншоты/` репозитория.

## 3. Кнопки и энкодеры

### Кнопки

| Кнопка | Действие |
| --- | --- |
| **OCT− / OCT+** | Октава (−2 … +2). В диалоге: OCT− = **НЕТ**, OCT+ = **ДА**. В REC на зажатом триггере — микротайминг шага. |
| **FX** | Страница эффектов (delay / reverb / chorus). |
| **SEL** | Страница TRACKS (уровни и MUTE треков). **SEL + белая клавиша** — выбор трека. |
| **ENV** | Страница огибающих (OSC1 / OSC2 / FREE ENV). Повторное нажатие циклически переключает страницы. |
| **LFO** | Страница LFO (4 LFO на трек). **Удержание ~0.5 с** — LFO MAP (привязка LFO к параметру). |
| **EDIT** | Короткое нажатие — выбор паттерна, удержание 2 с — выбор банка. В REC — окно TRIG: RETRIG / R.LEN / R.VEL / COND (повторное EDIT — назад). |
| **GLO** | Глобальные настройки: вкладки **AUDIO / MIDI / SPEAKER / USB**. Удержание + белая клавиша — выбор вкладки. |
| **HOME** | Shift: открывает комбинации (см. ниже). На SEQ — EUCLID, на NOTE TRIG в REC — обзор микротайминга. |
| **SAVE** | Коротко — `SAVE PATTERN?`; удержание 2 с — сохранить звук дорожки в пресет (`PRESET SAVED`). |
| **ARP** | Страница арпеджиатора. |
| **SEQ** | Страница секвенсора. Удержание + белая клавиша — страница паттерна. **HOME + SEQ** — EUCLID. |
| **PLAY** | Запуск / стоп. **HOME + PLAY** — экран BPM / CLICK с диагностикой. **PLAY + REC** — Live Record. |
| **REC** | Вход / выход из пошагового секвенсора. **REC + PLAY** — Live Record. |

### Чёрные клавиши (OP1–OP4)

Открывают страницы синтеза (в режиме записи или при зажатом HOME):

| Клавиша | Страница |
| --- | --- |
| **OP1** (F#3) | NOTE TRIG |
| **OP2** (G#3) | OSC |
| **OP3** (A#3) | AMP (повторное нажатие — вкладка SEND) |
| **OP4** (C#4) | FLT |

Удержание OP + белая клавиша — переключение вкладки внутри страницы.

### Энкодеры

| Энкодер | Действие |
| --- | --- |
| **K1–K4** | Четыре параметра текущей страницы (подписаны внизу экрана). При зажатом HOME — альтернативные параметры (см. ниже). |
| **SELECT** | Контекстный: громкость активного трека, выбор банка / трека / BPM, да/нет в диалогах. |
| **ALGO** | Алгоритм синтеза: **VA**, **WAVETABLE** или **FM** — меню с подтверждением (OCT+ применить, OCT− отмена). |
| **PRESET** | Пресеты A01…A32. Без зажатого триггера меняет звук дорожки; с зажатым — пишет пресет в шаг. |

### Комбинации

| Комбинация | Действие |
| --- | --- |
| **SEL + белая клавиша 1–6** | Выбор звуковой дорожки 1–6. |
| **SEL + белая клавиша 13–16** | Выбор MIDI-дорожки: 13 → M4, 14 → M3, 15 → M2, 16 → M1. |
| **SEL + OP1..OP4**, **SEL + D#4 / F#4** | Mute звуковых дорожек 1–4 (F#3, G#3, A#3, C#4) и 5–6 (D#4, F#4): слева направо чёрные клавиши = дорожки 1…6. |
| **SEL + HOME + OP1..OP4** | Mute MIDI-дорожек M1…M4. Также SEL + D#5 / C#5 / A#4 / G#4 = M1 / M2 / M3 / M4. |
| **HOME + OP1..OP4** | Открыть страницу NOTE TRIG / OSC / AMP / FLT. |
| **OP (удерж.) + белая клавиша** | Переключение вкладки страницы. |
| **SEQ (удерж.) + белая клавиша** | Выбор страницы паттерна 1–8. |
| **HOME + SEQ** | EUCLID вместо SEQ PAGE (переключает туда и обратно). |
| **HOME + PLAY** | BPM / CLICK: CPU, XRUN, MAX, UND, MISS, LIMdB. |
| **PLAY + REC** (одновременно) | Live Record (запись налету). |
| **REC + EDIT** | TRIG CONDITION: RETRIG / R.LEN / R.VEL / COND. |
| **GLO + EDIT** | Очистить всю automation текущего трека. |
| **EDIT + OCT−** | Очистить automation четырёх ручек текущего меню. |
| **GLO + SAVE** (коротко) | `SAVE BANK?` — сохранить весь банк (вне REC). |
| **SAVE 2 с** | Сохранить звук дорожки в пресет. |
| **HOME + SAVE (2 с)** | Режим обновления прошивки. |
| **Зажать триггер + OCT− / OCT+** | Микротайминг шага, только в REC. |
| **Зажать триггер + HOME** | Обзор микротайминга 16 шагов на NOTE TRIG в REC. |
| **Зажать триггер + PRESET** | Пресет в шаг (7-й p-lock слот). |

При зажатом **HOME** ручки K1–K4 дают альтернативные параметры:

| Меню | HOME + ручки |
| --- | --- |
| AMP | K2 = DRIVE вместо DIST |
| FLT, стр. 1/2 | K4 = D/WET вместо ENV |
| FLT, стр. 3/4 | DRIVE / PAN / VOL огибающей фильтра |
| LFO | MODE / SYNC / SPEED; для TIDES — MODE / SLOPE / SMOOTH / SHIFT |
| ENV (FREE) | K1/K2 = DEST / DEPTH |
| MIDI > LFO | Дополнительные параметры линий CC |

## 4. Треки

M-WORM имеет **6 звуковых треков**. Каждый трек — полностью независимый:

- свой звуковой патч (свои OSC, AMP, ADSR, фильтры, LFO, посылы);
- свой алгоритм — **VA** или **FM**;
- своя секвенция на 128 шагов;
- свои настройки секвенсора (длина, направление, скорость, свинг, страницы).

Выбор трека: зажми **SEL** и нажми белую клавишу 1–6 (на экране TRACKS — список треков
с уровнем и числом шагов). Всё, что ты редактируешь на страницах синтеза, относится
к **активному треку** (номер в верхней строке экрана).

Эффекты (delay / reverb / chorus) — общие; каждый трек лишь посылает в них свой уровень
(AMP → SEND).

## 4a. MIDI-треки (M1–M4)

Помимо 4 звуковых треков есть **4 MIDI-трека** — полноценные треки с секвенцией, но
вместо синтеза они шлют MIDI по **USB**.

- Выбор: **SEL + белая клавиша** — клавиши 16 / 15 / 14 / 13 = **M1 / M2 / M3 / M4**
  (звуковые треки 1–4 — по-прежнему клавиши 1–4).
- По умолчанию M1..M4 работают на MIDI-каналах 1..4.
- Страницы MIDI-трека: CHAN (канал 1–16), PROG (Program Change, −1 = не слать),
  BANK MSB/LSB, VOL (CC7), PAN (CC10), квантизация, MUTE и др.
- **4 LFO на CC**: у каждого трека 4 линии; в каждой — номер CC, BASE, DEPTH, SPEED,
  WAVE, SYNC, PHASE. LFO качает значение CC вокруг BASE.
- **P-lock**: зажми шаг и покрути ручку — на этом шаге уйдёт CC / PC / банк / VOL / PAN.
  Шаг должен быть включён. Всего 7 слотов на шаг, 7-й отдан под пресет шага.
- **Микротайминг** работает и на MIDI-дорожках (REC + OCT± на зажатом шаге).
- **Арпеджиатор** играет и по MIDI: страница ARP (удерживай кнопку ARP для переключения
  вкладок), параметры MAM/MAS/MAO/MAG (режим, шаг, октавы, гейт).
- **ARP>MIDI** (вкладка 2 ARP): ноты арпеджиатора звуковых треков дублируются
  на выбранный MIDI-трек.
- Mute MIDI-трека: **SEL** + чёрная клавиша **D#5 / C#5 / A#4 / G#4** = M1 / M2 / M3 / M4
  (как аудио-мьюты на OP1–4; звучащая дорожка — клавиша горит ярко, заглушенная — тускло).
  По-прежнему работает и HOME+OP. **GLO → MIDI → OCT+** — panic (All Notes Off).

## 5. Страницы синтеза

### NOTE TRIG (OP1)

Нота по умолчанию (ROOT), Velocity, длина ноты (LEN), Probability. В записи (REC) кнопка **EDIT** заменяет ручки окном **TRIG**:

- **RETRIG** — частота повторов OFF / 1/2 / 1/4 / 1/8 / 1/12 / 1/16 / 1/24 / 1/32 / 1/48 / 1/64;
- **R.LEN** — длительность серии: LEN (как длина ноты) или 1 / 2 / 4 / 8 / 16 шагов;
- **R.VEL** — наклон громкости серии (−63…+63): минус — затухание (fade-out), плюс — нарастание;
- **COND** — Trig Condition (12 значений: `--`, 1:2 … 8:8).

На экране — удары серии столбиками (высота = velocity). Значения пишутся в зажатый шаг (в Live Record — в текущий);
без зажатого шага они становятся значениями для новых шагов. Новый шаг дорожки обрывает идущую серию прошлого.
Работает и на MIDI-дорожках.

Вкладка 2: триггеры фильтра, LFO, портаменто.

### OSC (OP2)

Доступны три алгоритма — **VA**, **WAVETABLE (WT)** и **FM**. Движки HIVE / CHIP / TOY / AT / GS / ELMYRA удалены;
старые патчи с ними открываются как **VA**.

- **VA** — виртуальный аналог, только обычные волны: WAVE (`SIN TRI SAW SQR PLS NOI`), PW (активен только у PLS),
  TUNE, OCT, DETUNE, SUB, PITCH, LEVEL.
- **WAVETABLE (WT)** — только таблицы: **TABLE** — 5 основных `PWN PPG VIRUS VOCAL MELLO` (по 64 кадра) ·
  7 пользовательских слотов `U1..U7` (WTABLE.WPT) · 40 библиотечных (один цикл). Вторая ручка:
  у основных таблиц **FRAME** (листает 64 кадра с плавным морфингом; на экране «водопад» кадров и счётчик `32/64`),
  у USER/LIB — **BEND** (фазовое искажение, %; исходная форма пунктиром). Основные таблицы очищены от постоянной
  составляющей и выровнены по громкости кадров — FRAME можно модулировать LFO/ENV без щелчков.
- **FM** — 4-операторный FM как в Digitone (операторы **C, A, B1, B2**). Страница OSC в режиме FM имеет 7 вкладок
  по 4 ручки; вверху — схема выбранного алгоритма (стрелка = модуляция, линия вниз = выход, петля = FDBK) и ratio:
  1. **ALGO** (1–8) · **RAT C** · **RAT A** · **RAT B** (пара ratio B1:B2, например `1:2`)
  2. **HARM** (−26…+26, гармоники несущей C: пила / пила-редукция / чёт-нечёт / квадрат / колокол) · **DTUN** · **FDBK** · **MIX**
     (кроссфейд выходов X и Y; 0 = середина)
  3. **OFS C / OFS A / OF B1 / OF B2** — точная подстройка ratio каждого оператора (шаг 1/16)
  4. **ENV A**: ATK / DEC / END / LEV — огибающая индекса оператора A; 5. **ENV B**: то же для B1/B2 (LEV B — общий уровень B)
  6. **DEL A · TRG A · RST A · PHRT** (PHRT: OFF / ALL / C / AB / A+B2 — на какие операторы сбрасывается фаза при ноте)
  7. **DEL B · TRG B · RST B** (TRG — перезапуск огибающей при новой ноте, RST — с задержкой или без)
  Алгоритмы (по Appendix A.3 мануала Digitone; у каждого два выхода X и Y, MIX — кроссфейд между ними, −64 = только X, +63 = только Y):
  1 A>C, B2>B1>C — X=C, Y=B1 · 2 A>C, B2>B1 — X=C, Y=B1 · 3 A>(C, B2, B1) — X=C+B2, Y=B1 · 4 B2>B1>A>C — X=C, Y=B1 ·
  5 (B1+B2)>A>C — X=C, Y=A · 6 (A+B2)>(C, B1) — X=C, Y=B1 · 7 A>C, B2>B1 — X=C+A, Y=B1+B2 · 8 A>C, B2 и B1 несущие — X=C+B2, Y=B1.
  FDBK у алгоритмов 1/3/6/7 — на A, у 2/4 — на B2, у 5/8 — на B1. Выходы A и B в 7/8 «сплошные» (идут через огибающую оператора).
  Параметры у каждого трека свои, все модулируются LFO. При переключении на FM слоты OSC получают значения FM
  по умолчанию, при возврате на VA/WT — прежние умолчания VA/WT (старые FM-патчи звучат иначе, это новый движок).

Вкладки: VA — OSC1/OSC2 по 2 вкладки (всего 4); WT — 2; FM — 7.

### Выбор DEST (LFO / FREE ENV)
Экран как в Digitone: слева группа и имя выбранной цели, справа список с заголовками групп и полосой прокрутки.
Порядок зависит от движка: у **FM** сначала группа SYN в порядке мануала Digitone (Algorithm … B2 Offset, затем
составные **Pitch All, Pitch A+B2, Ratio All, AB Level/Attack/Decay/End/Delay**), у VA/WT — OSC1/OSC2; дальше AMP,
FLT, SEND, DELAY, REVERB, CHORUS, AENV, FENV, LFO, FREE. Индексы целей в банках не менялись — старые банки совместимы.

### AMP (OP3)

Дисторшн (D/WET + DIST), TRANSIENT, пан, громкость, драйв. При зажатом **HOME** K2 = DRIVE
вместо DIST. Вкладка SEND — посылы в delay/reverb/chorus.

### FLT (OP4)

Два фильтра (FLT1 / FLT2), каждый: CUTOFF, RESO, TYPE (OFF / LP / HP / BP), ENV-глубина;
на вкладках 1/2 при зажатом **HOME** K4 = **D/WET** вместо ENV. График показывает АЧХ
(20 Гц…20 кГц, ±36 дБ) с учётом D/WET; пунктирная вертикаль = база CUTOFF, сплошная игла —
живое значение с модуляцией.

Вкладки 3/4 — огибающие фильтров **E1 / E2** (ATK / DEC / SUS / REL); с **HOME** —
DRIVE / PAN / VOL огибающей.

### LFO (кнопка LFO)

**4 LFO на дорожку**. У каждого: DEST, SPEED, DEPTH, WAVE, MODE, SYNC, SLOPE, SMOOTH, SHIFT.
Формы: TRI / SIN / SQR / SAW / RND / EXP / RAMP / TDS. Режимы: FREE / HOLD / ONE / HALF.
При зажатом **HOME** K1–K4 = MODE / SYNC / SPEED, а для волны TDS — MODE / SLOPE / SMOOTH / SHIFT.
Удержание кнопки LFO ~0.5 с открывает **LFO MAP** — привязка LFO к параметру ручкой.

### ENV (кнопка ENV)

Три страницы: **OSC1 ENV** (E0), **OSC2 ENV** (E3), **FREE ENV** (E4) — свободный ADSR,
работающий как огибающая-модулятор (в духе LFO). У каждой ATK / DEC / SUS / REL.
Огибающие фильтров E1/E2 находятся на вкладках 3/4 страницы FLT.

**FREE ENV** (страница 3): через **HOME** — DEST (цель, как у LFO) и DEPTH (у составных DEST действует только главная цель). Пока нота звучит,
огибающая бежит ATK → DEC → SUS → REL; её значение (0…1) × DEPTH добавляется к DEST-параметру.
Классика: PW / INDEX или SEND-уровни эффектов (DLY/REV/CHO), но цель — любой модулируемый параметр.

### FX (кнопка FX)

Общие эффекты: Delay (TIME/FDBK/FILT/MIX), Reverb (SIZE/DECAY/DAMP/MIX), Chorus (RATE/DEPTH/DELAY/MIX).

### Отображение модуляции

Когда LFO или FREE ENV модулируют параметр, это видно на экране:

- **ручки** — стрелка едет к модулированному значению, точка на ободе показывает базу (куда повёрнута ручка);
- на LED дышат (пульсируют) зажатые клавиши — играющие ноты, а не произвольная клавиша от ручки;
- **AMP SEND** — полосы DLY/REV/CHO едут за модуляцией, риска отмечает базу ручки;
- **FLT CUTOFF** — пунктирная вертикаль = база, сплошная игла = живое значение;
- **FREE ENV** — на её странице пунктирная линия с меткой слева показывает текущий уровень огибающей.

## 6. Секвенсор

Каждый трек — секвенция на 128 шагов (8 страниц по 16).

### Пошаговый секвенсор (REC)

- Нажми **REC** — вход в пошаговый секвенсор (бегунок бегает, звука нет).
- **Белые клавиши 1–16** — включение/выключение шагов на текущей странице.
- **SEQ + белая клавиша** — выбор страницы (1–8).
- Зажми шаг и крути ручку — **P-lock** (значение параметра только на этом шаге).
  Слотов 7; 7-й зарезервирован под пресет шага.
- Выход: **REC** снова.
- В REC **C#5 (MONO)** / **D#5 (POLY)** листают страницы шагов (1…N) на ходу, в том числе
  с зажатым шагом; подсветка показывает границы. Вне REC это обычные ноты.
- Повторное нажатие на включённый шаг снимает триггер и полностью очищает шаг: микротайминг,
  p-lock’и, RETRIG, VEL/LEN/PROB/COND, нота и аккорд.

### Live Record (запись налету)

Зажми **REC** и нажми **PLAY** (или наоборот) — секвенсор играет, а белые клавиши
записывают ноты на лету.

### Параметры шага

- **ROOT / VEL / LEN / PROB** — нота, сила, длина, вероятность.
- **LEN** — длина ноты **в шагах**, как у Elektron: 0.063 / 0.125 / 0.25 / 0.375 / 0.5 / 0.625 /
  0.75 / 0.875 шага, затем 1/16 (1 шаг), 1/8 (2), 3, 1/4 (4), 5, 6, 7, 1/2 (8), 9 … **128 шагов**.
  Шаг — шаг самой дорожки (с учётом её SPEED). По умолчанию 2 шага (1/8). Быстрое кручение ручки
  ускоряется, так что до 128 можно долететь за пару оборотов.
- **Trig Condition** (REC + EDIT) — условия 1:2 … 8:8 (Elektron-стиль).
- **RETRIG / R.LEN / R.VEL** — повторы с наклоном громкости (см. NOTE TRIG).
- **Chord** — в аккордовом режиме записывается аккорд (до 4 нот).
- **Пресет на шаг** — зажать триггер и крутить PRESET. Пресет пишется как 7-й p-lock,
  звук самой дорожки не меняется. При воспроизведении пресет загружается перед обычными локами,
  поэтому ручки шага перебивают пресет. Окно `STEP PRESET` держится 2 с.
- **Микротайминг** — в **REC** зажать триггер и нажимать **OCT− / OCT+**: сдвиг шага в **процентах шага**
  (−100 … +100 %, минус — раньше, плюс — позже; 100 % = один шаг 1x). Окно показывает крупный процент
  и тот же сдвиг в **миллисекундах при текущем BPM** (например `−25%`, `−28.4 MS @ 132 BPM`), шкалу
  и сдвиги всех 16 шагов страницы. При удержании кнопки сдвиг ускоряется: 1 % → 2 % → 5 % на нажатие.
  Держа **HOME** на `NOTE TRIG` в REC — обзор `OFFSET, % OF STEP` (столбики вверх — позже, вниз — раньше).
  Метроном и индикатор доли сдвинуты на ту же задержку. Вне REC OCT± меняют октаву как обычно.

### Параметры секвенсора (SEQ)

Страница SEQ PAGE: число страниц, направление (`>>`, `<<`, `<>`, `??`), скорость (1/2×, 1×, 2×),
свинг (50…75%), длина (до 128 шагов). **HOME + SEQ** открывает **EUCLID**:
E.HITS 0…16, E.OFS 0…15, E.LIMIT 1…16, E.MUTE.

## 7. Арпеджиатор

Кнопка **ARP**: режим (OFF / UP / DOWN / UPDN / RND), скорость, октавы 1…4, гейт.
Зажми аккорд на клавиатуре — арпеджиатор раскладывает ноты во времени.
Вкладка 2 — **ARP > MIDI** (OFF / M1…M4): дублирование нот арпеджиатора на MIDI-дорожку.

## 8. Сохранение и банки

- **SAVE** (коротко) — `SAVE PATTERN?` → OCT+ да / OCT− нет. Пишется паттерн и проект.
- **SAVE удержать 2 с** — звук текущей дорожки сохраняется в выбранный пресет
  (`PRESET SAVED`); HOME+SAVE при этом означает режим обновления.
- **GLO + SAVE** (коротко, вне REC) — `SAVE BANK?` → OCT+ да / OCT− нет. Пишется весь банк.
- **EDIT** (коротко) — выбор паттерна; **EDIT 2 с** — выбор банка.
  8 банков A–H × 16 паттернов = **128 паттернов**.
  **Паттерн — это снимок всего:** секвенции всех 6 дорожек, звук каждой дорожки (патч, длина/направление/свинг, MUTE, automation) и общие FX/параметры.
  Переключение паттерна меняет всё сразу (на ходу — на границе такта). Новый (ещё не записанный) паттерн приходит с пустыми секвенциями, а звук и эффекты
  берёт текущие. BPM общий на весь проект. При смене банка включается паттерн 1 нового банка.
  Переключение не пишет во флеш: банк держится в памяти, изменённые сектора записываются в простое (STOP, через ~1,5 с), SAVE и смена банка пишут сразу.
  Если плотный паттерн не помещается в банк (36 КБ на 16 паттернов), появится «BANK FULL», и вы останетесь на текущем паттерне с неповреждёнными правками.
- **PRESET** — 32 слота **A01…A32**. Все стартуют с заводскими звуками; любой можно
  перезаписать удержанием SAVE 2 с. Пользовательский пресет хранится в NOR и не теряется
  при смене паттерна. Пресет меняет только звук дорожки (OSC/AMP/SEND/FLT/LFO/ENV),
  FX и глобальные параметры не трогает.
- **Пресет на шаг** — см. раздел 6; занимает 7-й p-lock слот.

Паттерны и настройки треков сохраняются во флеш-памяти и переживают выключение.
На компьютере банки видны как диск `M-WORM PATTERNS` с файлами `BANK_A.WPB … BANK_H.WPB`
(режим GLO → USB → MASS STORAGE); для работы с отдельными паттернами есть
утилита `mworm_bank_tool.py`.

## 9. MIDI и USB-аудио

- **MIDI in**: USB, TRS-джек. Ноты играют как клавиши (квантизация по гамме/аккорду).
- **GLO → USB** (вкладка 4): **USB MODE** — `MASS STORAGE` или `AUDIO + MIDI`.
  Выбор ручкой SELECT, **OCT+ применяет, OCT− отменяет**. Одновременно только один режим.
  - *MASS STORAGE* — FM-1 монтируется как диск `M-WORM PATTERNS` (8 файлов банков);
    аудио и MIDI в этом режиме недоступны.
  - *AUDIO + MIDI* — обычная работа: USB-аудио и USB MIDI.
- **GLO → MIDI** (вкладка 2): **USB MIDI MODE** — `COMPUTER (DEVICE)` / `EXTERNAL (HOST)`.
  - *COMPUTER (DEVICE)* — по умолчанию: FM-1 подключён к компьютеру (Ableton, DAW) и USB-аудио.
  - *EXTERNAL (HOST)* — FM-1 становится USB-хостом: подключай синтезатор/контроллер (напр. Roland S-1) кабелем.
    Нужен **активный хаб или питание от самого синта** — FM-1 не даёт 5 В на порт. В этом режиме компьютера нет
    (нет USB-аудио/обновления); возврат — тем же переключателем. После перезагрузки всегда COMPUTER.
  - Строка статуса: STARTING / LOOKING FOR DEVICE / CONNECTED. При смене режима и потере устройства — panic;
    у нового устройства PROG/BANK/VOL/PAN/CC посылаются заново. **OCT+** в этой вкладке — PANIC.
- **GLO → AUDIO** (вкладка 1): выход USB-аудио — `MASTER 24BIT 48K`,
  `TRK 1-3 16BIT 44K` (дорожки 1–3 стерео-парами, 6 каналов), `TRK 4-6 16BIT 44K` (дорожки 4–6, 6 каналов)
  или `FX 16BIT 44K` (возвраты delay / reverb / chorus, 6 каналов). Выбор SELECT, применение OCT+.
- **GLO → SPEAKER** (вкладка 3): динамик/наушники FM-1 можно приглушить при подключённом USB
  (USB-аудио при этом не затрагивается).
- **MIDI out**: клавиши шлют ноты по USB; MIDI-треки M1–M4 — ноты, CC, PC, bank (см. 4a).
- **USB-аудио**: FM-1 — звуковая карта. Компьютер записывает выход FM-1 (вход
  «M-WORM FM-1») и может проигрывать через него (выбери «M-WORM FM-1» как выход).
  Громкость — ручкой MASTER.

## 10. Возврат к стоку

**Вариант 1 — HOME + SAVE (2 секунды):**
Зажми одновременно HOME и SAVE, держи ~2 с → на экране «UPDATE MODE / RELEASE TO FLASH».
Устройство уходит в режим обновления — прошей сток M-VAVE (`FM-1.fwsc` V15/V16) через
M-UPGRADE или `./flash.sh FM-1.fwsc`.

**Вариант 2 — REC при включении:**
Выключи FM-1, зажми REC, включи и держи ~1 с → режим обновления.

**Safe Mode** (если прошивка падает дважды): на экране «NO SOUND. USB IS ON».
PLAY — попробовать снова, REC — режим обновления.

Прошивка пишется только в область приложения (`0x4000–0x92FFF`); загрузчик и mask ROM
не трогаются, поэтому устройство всегда восстанавливается по USB.

## 11. Устранение неполадок

**Нет звука:** подними MASTER; нота играет, только пока клавиша нажата. Проверь, что
громкость трека (SEL → TRACKS) и LEVEL (AMP) не на нуле.

**Хрип/треск в USB-записи:** в этой сборке включён глубокий буфер записи (`FM1B_UAC_DEEP`).
Если треск появляется на очень плотных паттернах (все 6 треков + тяжёлый реверб) — это
перегрузка рендера; отключи FX или часть эффектов-посылов. Смотри **HOME + PLAY**:
`CPU`, `XRUN`, `MAX`, `UND`, `MISS` и `LIMdB` (сжатие лимитера; держится ~1 с,
значение больше 0 дБ означает слышимые искажения). Лог: `tools/fm1_remote.py log`.

**Флешер не находит FM-1:** data-кабель (не зарядка), прямо в порт, закрой другие MIDI-программы.
Проверь порт: `./flash.sh --info`.

**FM-1 не стартует после прошивки:** два неудачных старта → Safe Mode. Верни сток и прошей заново.

**Залипшие ноты:** выключи и включи питание (сброс голосов).

**Пресет шага не применяется:** убедись, что шаг включён; пресет пишется только на зажатый
триггер и хранится вместе с шагом — при смене паттерна лок уходит со старыми шагами.

## LIVE режим

**Вход / выход:** `HOME + GLO` (в любом порядке). Всё ниже работает только в LIVE; REC, FX, ENV, LFO, ARP в LIVE не работают.

| Что | Действие |
| --- | --- |
| Мьюты | **HOME** по нажатию открывает/закрывает каналы: белые клавиши 1–6 = T1–T6 (слева), 13–16 = M4…M1 (справа), как в SEL. Повторное нажатие HOME возвращает клавишам обычный режим. Пока каналы открыты, клавиша-мьют мигает на каждом реальном сработавшем триггере секвенсора (включая EUCLID и Conditional): звучащий трек — ярко, заглушённый — тускло. На экране активность дорожек не показывается. |
| Макросы | **SELECT, ALGO, K1–K4** крутят назначенные параметры (по умолчанию BPM, FILTER, FLT1 CUT/RESO, SEND DELAY/REVERB). Положения ручек, BPM, банк/паттерн видны на экране; активность дорожек — на клавишах-мьютах. |
| Редактор макросов | **EDIT**. Покрутите нужный энкодер — он выбирает параметр (любой параметр дорожки, BPM, FILTER/CRUSH/DUCK, уровни дорожек, MIDI VOL/PAN и CC-линии). Клавиши 1–6 выбирают слот, клавиша 16 очищает, **OCT−/+** — дорожка цели (CUR = выбранная), **PRESET** — набор для всего банка (BANK) или только этого паттерна (PTN). EDIT — выход. |
| Паттерны | При входе в LIVE сразу выбирается **A01** текущего банка, даже во время игры. Белые клавиши 1–16 (или PRESET) — выбрать паттерн; переключение через время из **SEQ**. **OCT−/+** — банк. На клавишах горит только текущий (дышит) и ожидающий переключения паттерны. Без вмешательства паттерны идут друг за другом (цепочка). |
| SEQ | SWITCH TIME: BEAT / 1 / 2 / 4 / 8 BAR (по умолчанию 1 BAR); CHAIN (по умолчанию 2 PASS): OFF / PASS (один проход) / 2 PASS / 4 PASS / 1…16 BAR; ORDER (по умолчанию USED): USED / ALL / RANDOM. |
| Эффекты | Чёрные клавиши (удержание): REP 1/16, REP 1/32, REP 1/8, REVERSE, TAPE STOP, FREEZE, LPF, HPF, CRUSH, DUCK. Макросы FILTER / CRUSH / DUCK задают их постоянную глубину. |

Набор макросов паттерна хранится в записи паттерна (сохраняется по SAVE), набор банка и настройки SEQ — в секторе проекта.

## Совместимость со старыми банками

Банки, записанные прошивкой с прежними единицами, читаются с пересчётом: прежний LEN (1/16, 1/8, 1/4, 1/2, 1/1 =
1, 2, 4, 8, 16 шагов) становится 1 / 2 / 4 / 8 / 16 шагов новой шкалы, прежние тики микротайминга (1/24 шага)
пересчитываются в проценты (1 тик ≈ 4 %). Шаги с «круглыми» значениями пишутся в прежнем 13-байтовом формате,
остальные — с двумя дополнительными байтами.
