## Движок (worm_synth.c, переписан с нуля)
Один файл ~480 строк вместо synth+filters+lag+smp (~3000). Блок делится на две фазы между CPU0 и CPU1: голоса (разбиение подбирается по замеренной стоимости, таймер 24 МГц) и FX (reverb — CPU1; delay, chorus, слияние шин, мастер и лимитер — CPU0). Звук совпадает с одним ядром бит в бит; при отказе CPU1 состояние голосов и reverb откатывается, блок досчитывается на CPU0.
- Голос: 1 моно на дорожку. 2 OSC + SUB (VA: sin/tri/saw/sqr/pulse/noise; FM: 2-оп PM, 4 алгоритма), ADSR x5,
  фильтр на каждый OSC (F1 -> OSC1+SUB, F2 -> OSC2; TPT-SVF OFF/LP/HP/BP, свой ADSR), amp: OFF/OVR/DIST/FUZZ,
  transient, pan/vol, 3 send'а. 4 LFO на дорожку, p-lock и automation как раньше.
- FX общие: delay (темпо, LPF в обратной связи), reverb (4 comb + 2 allpass), chorus; простаивающий FX не считается.
- Мастер: DC-блок + лимитер по пику блока + мягкое колено.
- Правила стоимости: на сэмпл только + * сравнения (без sin/exp/tan/div); огибающие/LFO/коэффициенты фильтра —
  раз в блок (BL=64, секвенсор режет рендер по 64), аудио рампится линейно между блоками. Фаза осцилляторов — uint32,
  синус — парабола. Стадии (gen -> env -> filter -> sum -> amp -> out) — узкие циклы, неактивные стадии бесплатны.

## MIDI-треки (worm_midi.c)
- 4 MIDI-трека (NMTRK), 4 CC-LFO-линии на трек (NMLANE); виртуальные id параметров (>=NP, MLIST) — без раздувания worm_pinfo/UI.
- Рабочая копия в W.p, сохранение в W.mt[k].p[NMP]; `worm_trk_sync`, `worm_mtrk_load/store`.

- Тест: tests/midi_tracks.txt (хост-симулятор).

## Нагрузка, ретриггер, MIDI-мьюты (2026-11)
Цель: 104% CPU / XRUN под полной нагрузкой (6 дорожек, 2 OSC, 2 фильтра с ENV, 4 LFO, все посылы, automation, 4 MIDI) и пропуски триггеров.
Хост-бенчмарк (zig cc -O2, 256 кадров на блок, сцена «всё включено»): среднее 120–157 → 76–80 мкс (−37…−50%), p99 −30…−55%.
- **Рендер чанками по 32 сэмпла** (worm_seq.c): раньше блок дробился на каждой границе события (шаги 4 дорожек, mTime, арп,
  MIDI-шаги и ворота нот) — у каждого обрывка полная накладная синта. Теперь события на границе чанка (дрожание ≤ 0.7 мс),
  перелёт переносится в следующий интервал (часы дорожек, MIDI, арп — со знаком, темп не плывёт).
- **Automation**: значение на шаге кешируется раз на шаг (worm_aut_gen — сброс при правке), раньше O(64) поиск в каждом mp().
- **Шины и LFO**: обнуляются только строки активных дорожек / прошлые цели LFO (было memset ~9 КБ на блок).
- **Reverb**: FDN на половинной частоте (22.05 кГц) — вдвое дешевле, а линии по времени вдвое длиннее: хвост глубже;
  feedback до 0.97. Delay/chorus: константы на блок, а не на сэмпл.
- **Призраки** (украденные голоса): хвост ≤ 80 мс (держащаяся нота — 10 мс); раньше дозвучивал весь REL -> 12 голосов.
- **Удалены** WT / HIVE / CHIP / TOY (меньше кода в XIP-кеше). id параметров сохранены; старые банки -> VA.
- **FM: MIX** — кроссфейд OSC1↔OSC2 равной мощности (P_OL2), вместо двух громкостей.
- **Перегруз**: два плохих блока подряд — мягко (ускорить хвосты призраков / погасить тихий release-голос), держащиеся ноты
  и новые триггеры не трогаются; настоящий xrun — жёстко (worm_synth_shed_hard). Раньше потолок голосов снижался уже
  при одиночном пике — это и были «пропуски триггеров».
- **Гонки**: живые ноты и PLAY/STOP из главного цикла -> SPSC-очередь, разбирается в аудио-потоке.
- **Пул триггеров** NPD 10->12 (MIDI 8->12); при переполнении триггер не теряется (крадётся хвост ретриггера / играется сразу).
- **Баги**: PROB 0 всё равно играл (rnd%127 > prob); индекс хоруса рос бесконечно и через ~6 мин терял точность во float
  (ступеньки/треск хоруса); worm_lfo_value читал за NLFO; worm_effective писал e[id] для id ≥ NP.
- **RETRIG** (NOTE TRIG, REC+EDIT): RETRIG / R.LEN / R.VEL / COND; хранится в свободных битах шага (формат банка тот же,
  старые банки читаются как «ретриггер выключен»). Тест: tests/core/t_retrig.c.
- **MUTE MIDI-дорожек**: SEL + D#5 / C#5 / A#4 / G#4 = M1..M4, подсветка как у аудио-мьютов.
- Не проверено на железе: прошивка не собиралась тулчейном JieLi; RAM: .pool +≈1.3 КБ (PD 10->12 записей и +20 Б на запись, MPD 8->12), .bss +≈1.6 КБ (кеш automation). По комментарию worm_store.c в пуле свободно ~10 КБ.


## Моно-дорожки (6 голосов)
- Пул голосов, кража, призраки, юнисон/VOICES, POLY и сброс голосов при перегрузе удалены: 6 дорожек = 6 моно-голосов (`NVOICE = NTRK = 6`). Хранение: дорожки 1–4 — как раньше, 5–6 — хвост записи паттерна (маска + те же записи; нет тронутых — хвоста нет, старые банки читаются). - Слоты параметров MODE/VOICES/UNISON/SPREAD оставлены зарезервированными (`P_RS0..P_RS3`), чтобы формат сохранённых банков не изменился.
